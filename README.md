# Blog Next.js

Projeto desenvolvido com Next.js utilizando App Router, rotas dinâmicas e SEO dinâmico.

## Funcionalidades

- Listagem de artigos
- Rotas dinâmicas por slug
- SEO dinâmico com generateMetadata
- Geração estática com generateStaticParams
- Server Components
- Estilização com CSS Modules

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- CSS Modules
